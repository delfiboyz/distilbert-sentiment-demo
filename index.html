What the model reads

    The text is lowercased and split into WordPiece tokens. Pieces that start with ## continue the word before them. [CLS] and [SEP] mark the start and end. Anything past 512 tokens is cut off.

    Sample reviews

    Short movie-review lines like the SST-2 data the model was fine-tuned on, including a sarcastic one, a mixed one and a neutral one. Select a line to load it into the editor.

      Use it in your own code

      import { pipeline } from '@huggingface/transformers';

const classify = await pipeline(
  'sentiment-analysis',
  'Xenova/distilbert-base-uncased-finetuned-sst-2-english',
  { dtype: 'q8' },
);

await classify('A warm, funny, and beautifully acted film.');
// The result appears here once the model has loaded.

      On a normal web host the model downloads from the Hugging Face Hub the first time and is cached by the browser. This page ships the model files itself because its host blocks outside downloads.

      Model: Xenova/distilbert-base-uncased-finetuned-sst-2-english, the ONNX export of DistilBERT fine-tuned on SST-2 (Stanford Sentiment Treebank), quantized to 8-bit. Runtime: ONNX Runtime Web on WebAssembly, single thread.

      The model only knows two labels and was trained on movie reviews. It gives near-certain scores even to neutral text, and mixed reviews usually land on one side with high confidence.
